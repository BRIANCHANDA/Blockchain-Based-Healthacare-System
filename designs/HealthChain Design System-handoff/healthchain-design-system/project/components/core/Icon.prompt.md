Inline stroke icon (mirrors Lucide; no runtime dependency). Monochrome, inherits color.

```jsx
<Icon name="shield-check" size={20} />
<Icon name="alert-triangle" color="var(--critical)" strokeWidth={2.4} />
```

See the `IconName` union in `Icon.d.ts` for the full set (lock, shield, heart-pulse, pill, flask, scan, qr-code, fingerprint, link…). In production RN use `lucide-react-native` with the same names.
