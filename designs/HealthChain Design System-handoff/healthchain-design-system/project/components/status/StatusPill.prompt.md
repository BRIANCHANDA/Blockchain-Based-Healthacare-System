One status vocabulary reused across visits, prescriptions, labs, referrals and access grants. Color + icon + label together — never color alone.

```jsx
<StatusPill status="in-progress" />
<StatusPill status="dispensed" size="sm" />
<StatusPill status="granted" />
```

`status`: in-progress · completed · cancelled · pending · accepted · rejected · prescribed · dispensing · dispensed · ordered · resulted · locked · granted · revoked · expired · approved · denied. `size` sm|md, `solid` for a filled variant.
