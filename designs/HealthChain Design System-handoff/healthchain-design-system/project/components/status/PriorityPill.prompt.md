Clinical priority pill. Color, icon and weight all escalate with severity; `critical` is a solid fill so it cannot be missed.

```jsx
<PriorityPill priority="routine" />
<PriorityPill priority="urgent" />
<PriorityPill priority="emergency" />
<PriorityPill priority="critical" />
```

`priority`: routine · urgent · emergency · critical. `size` sm|md. Pair with `StatusPill` on visit and referral cards.
